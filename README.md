# 🎬 MovieCasting

Мобільний додаток для підбору фільмів у стилі Tinder + TikTok. Працює на **Android та iPhone**, повністю безкоштовний.

| Розділ | Що вміє |
|---|---|
| 🔥 **Кастинг** | Картки фільмів: свайп **вправо** — подобається, **вліво** — ні, **вгору** — вже бачив. Кнопка «скасувати». Фільтри: жанри (включити/виключити), роки та епохи, мінімальний рейтинг, кількість оцінок, тривалість, мова оригіналу, країна, сортування. Режими: **Уся база**, **✨ Для тебе** (підбір за вашими вподобаннями), **🍿 Що сьогодні?** (настрій + час + епоха → 5 фільмів), **👫 Удвох** (спільна колода з другом, метчі). Пошук будь-якого фільму. |
| ▶️ **Трейлери** | Вертикальна стрічка трейлерів як у TikTok: гортаєш вгору, трейлер грає сам. Вкладки «Популярне / Скоро / У кіно / Топ», кнопки ❤️, 👁, «Про фільм», «Поділитись», YouTube. |
| 📚 **Бібліотека** | Обране, переглянуте і відхилене. Пошук, сортування, фільтр «без переглянутих», кнопка 🎲 «Що подивитись?», власна оцінка 1–10 для переглянутих. |
| 👤 **Профіль** | Ім’я та аватар, рівень кіномана, статистика (свайпи, % вподобань, години кіно, трейлери), активність за тиждень, улюблені жанри й епохи, налаштування ключа API та мови. |

Картка фільму: постер, опис, рейтинг TMDB, посилання на **IMDb**, режисер, актори, бюджет/збори, трейлер.

## 👫 Кастинг удвох (налаштування один раз)

Спільні кімнати зберігаються в Supabase поруч з акаунтами. Один раз відкрийте **Supabase → SQL Editor → New query**, вставте вміст файлу [`supabase/rooms.sql`](supabase/rooms.sql) і натисніть **Run**.

## Звідки фільми і навіщо ключ

IMDb не має безкоштовного офіційного API (лише платний через AWS). Тому додаток використовує **TMDB** — безкоштовну базу з понад мільйоном фільмів, де для кожного фільму є IMDb‑ідентифікатор, постери українською та трейлери з YouTube.

1. Зареєструйтесь на [themoviedb.org](https://www.themoviedb.org/signup) (безкоштовно).
2. Відкрийте [Налаштування → API](https://www.themoviedb.org/settings/api) і створіть ключ (тип «Developer», ціль — особисте використання).
3. Скопіюйте **API Key** або **API Read Access Token** і вставте в додатку: **Профіль → База фільмів → Зберегти ключ**.

Без ключа додаток працює в **демо-режимі** з 12 відомими фільмами.

## 🌐 Відкрити як сайт (iPhone і Android)

Додаток працює як веб-застосунок: **https://zharoslaw31.github.io/MovieCasting/**

- **iPhone (Safari):** кнопка «Поділитися» → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран» / «Встановити додаток».

Після цього MovieCasting відкривається з іконки на весь екран, як звичайний додаток. Кожна зміна в гілці `main` автоматично публікується (GitHub Actions → GitHub Pages) приблизно за 2–3 хвилини, тож на телефоні завжди найсвіжіша версія.

Необов’язково: щоб не вводити ключ TMDB на кожному пристрої, додайте його в репозиторії як секрет `TMDB_API_KEY` (Settings → Secrets and variables → Actions). Зверніть увагу, що тоді ключ буде видно в коді сайту; для безкоштовного ключа TMDB це некритично.

## Як запустити через Expo Go (для розробки)

Потрібно: комп’ютер з [Node.js 20+](https://nodejs.org) і застосунок **Expo Go** на телефоні ([Android](https://play.google.com/store/apps/details?id=host.exp.exponent) / [iPhone](https://apps.apple.com/app/expo-go/id982107779)).

```bash
git clone https://github.com/<ваш-логін>/MovieCasting.git
cd MovieCasting
npm install
npx expo start
```

Відскануйте QR-код камерою (iPhone) або в Expo Go (Android). Телефон і комп’ютер мають бути в одній Wi‑Fi мережі (або запустіть `npx expo start --tunnel`).

За бажанням ключ можна задати у файлі `.env` (див. `.env.example`), тоді його не треба вводити в додатку.

## Як зібрати APK для Android (безкоштовно)

```bash
npm install -g eas-cli
eas login               # безкоштовний акаунт expo.dev
eas build -p android --profile preview
```

Через 10–20 хвилин EAS дасть посилання на `.apk`, який можна встановити на будь-який Android. Для iPhone потрібен акаунт Apple Developer (платний), тому на iOS зручніше користуватись Expo Go.

## Технології

Expo SDK 58 · React Native · TypeScript · Expo Router · TMDB API · AsyncStorage (усі дані зберігаються локально на телефоні).

```
src/
  app/(tabs)/index.tsx      Кастинг (свайпи)
  app/(tabs)/trailers.tsx   Стрічка трейлерів
  app/(tabs)/library.tsx    Бібліотека
  app/(tabs)/profile.tsx    Профіль і статистика
  app/filters.tsx           Фільтри
  app/movie/[id].tsx        Картка фільму
  components/               Колода карток, плеєр, UI-елементи
  lib/tmdb.ts               Клієнт TMDB
  lib/store.tsx             Стан і збереження
```

Цей продукт використовує TMDB API, але не схвалений і не сертифікований TMDB.
